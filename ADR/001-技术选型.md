# ADR-001：技术选型

## 状态：已接受

## 背景
Long Agent 项目需要选择编程语言、Web 框架、数据库、LLM 接入方案。

## 候选方案

| 维度 | 方案A | 方案B | 方案C |
|------|-------|-------|-------|
| 语言 | Python 3.12+ | TypeScript | Rust |
| Web 框架 | FastAPI | Express.js | Actix-web |
| 数据库 | SQLite | PostgreSQL | MongoDB |
| LLM 接入 | OpenAI API | 本地 Ollama | Anthropic Claude |

## 决策
- **语言：Python 3.12+** — AI 生态最丰富，FastAPI 原生异步支持
- **Web 框架：FastAPI** — Pydantic 校验 + 异步 + 零成本扩展
- **数据库：SQLite** — 零运维 + MVP 数据量够用 + 单文件部署
- **LLM 接入：OpenAI API (gpt-4o)** — 能力强 + SDK 成熟，V2 扩展多模型

## 理由
- Python 在 AI/ML 领域生态压倒性领先
- FastAPI 的 Pydantic 集成减少大量样板代码
- SQLite 对单用户 Agent 场景足够，V2 可迁移到 PostgreSQL
- OpenAI API 是当前能力最强的通用模型

## 后果
- Python 性能不如 Rust（可接受）
- SQLite 不支持并发写入（MVP 单用户无影响）
- OpenAI 依赖外部服务（V2 增加本地模型回退）
