## 一、模块定位

理解层是 Agent 的"耳朵和大脑"，负责把用户输入转化为结构化意图。

**核心约束（主心骨）**：
> **宁可多问一句，不要猜错返工。置信度高于高阈值（0.85）直接执行，低于低阈值（0.50）追问，中间地带确认后执行。所有阈值从用户历史数据贝叶斯更新，禁止写死。**

## 三、模块规则

### U-001：意图解析双路径
- **快速路径**：本地规则表（`LOCAL_RULES`）命中 → 不调 LLM，置信度 1.0
- **语义路径**：LLM 解析 → 返回结构化 Intent
- **降级路径**：LLM 不可用或调用失败 → 关键词规则匹配

### U-002：意图类型枚举
- `memory_write`：写入记忆
- `memory_read`：读取记忆
- `memory_search`：搜索记忆
- `personality_update`：调整人格
- `llm_chat`：普通对话
- `unknown`：无法识别

### U-003：需要审批的意图类型
- `clear_memory`：清空记忆
- `reset_personality`：重置人格
- 其他意图 `requires_approval=False`

### U-004：置信度阈值（贝叶斯动态更新）
- 初始高阈值：0.85（信号检测理论 d'=1 时约 85%）
- 初始低阈值：0.50（随机猜测水平）
- 桶宽：0.05（20 个桶覆盖 [0,1]）
- 最小样本数：10（中心极限定理近似）
- 数据来源：按置信度分桶统计历史确认率，贝叶斯更新

### U-005：追问策略
- 置信度 < 低阈值 → 追问（最多 3 次）
- 追问模板 V1：固定 3 条，V2 由 LLM 动态生成
- 超过最大追问次数 → 返回 `Intent(type="unknown")`

### U-006：人格反馈规则（V1 快速路径）
- 关键词 → HEXACO 维度映射，如：
  - "太啰嗦" → X(外向性) decrease
  - "太冷漠" → E(情绪性) increase
  - "太死板" → O(经验开放性) increase
- V2 替换为 LLM 语义判断

### U-007：跑偏检查
- V1：简单关键词匹配检测执行偏离
- V2：LLM 语义相似度 + 4 个算法（贝叶斯/边际效益/决策树/健康度）

### U-008：上下文注入
- 意图解析时必须注入：人格参数 + 相关记忆 + 当前标准
- 带着记忆理解，不从零开始
