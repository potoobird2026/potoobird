## 一、模块定位

科学算法模块为 Agent 的所有"决策点"提供数学依据，确保每个参数都有来源（真理公式或 LLM 语义判断），禁止魔法数字。

**核心约束（主心骨）**：
> **所有参数通过真理公式或 LLM 语义判断决定。每个算法必须有科学依据引用（论文/定理/公式）。参数初始值来自科学依据，运行后从用户历史数据自适应调整。**

## 三、模块规则

### A-001：置信度阈值算法（贝叶斯 + 信号检测理论）

**科学依据**：
- 贝叶斯定理（Bayes, 1763）：`P(H|D) = P(D|H)·P(H) / P(D)`
- 信号检测理论（Green & Swets, 1966）：`d' = Z(击中率) - Z(虚报率)`

**参数来源**：
- 初始高阈值 0.85：d'=1 时最优决策点约 85%
- 初始低阈值 0.50：随机猜测水平
- 桶宽 0.05：20 个桶覆盖 [0,1]
- 最小样本数 10：中心极限定理近似
- 运行后：按置信度分桶统计历史确认率，贝叶斯更新

### A-002：追问预算算法（边际效益递减）

**科学依据**：
- 经济学边际效益递减规律
- 贝叶斯停止规则

**参数来源**：
- 初始预算 3 次：LLM 根据任务复杂度动态评估
- 边际效益阈值：从该用户历史追问数据拟合
- 运行后：每次追问后更新效益曲线

### A-003：追问策略算法（决策树）

**科学依据**：
- ID3 决策树（Quinlan, 1986）
- 信息增益最大化

**参数来源**：
- 决策树结构：由 LLM 根据意图类型动态生成
- 分支条件：从用户历史交互数据学习

### A-004：健康度评分算法（LLM 降级检测）

**科学依据**：
- 信息熵（Shannon, 1948）
- 语义相似度（余弦相似度）

**参数来源**：
- 阈值：从该用户历史对话数据拟合
- 语义相似度基准：LLM 评估

### A-005：人格调整算法（PID 控制器）

**科学依据**：
- 控制论（Ziegler & Nichols, 1942）
- PID 公式：`u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt`

**参数来源**：
- Kp=0.5, Ki=0.1, Kd=0.05：Ziegler-Nichols 方法整定
- 死区 5.0：防止过度敏感
- 最大调整量 10.0：防止单次反馈导致剧烈变化
- 积分上限 50.0：防积分饱和

### A-006：上下文压缩算法（三阶段）

**科学依据**：
- 信息重要性评分（TF-IDF + 位置权重 + 时间衰减）
- 动态规划（最优裁剪）
- 滑动窗口摘要

**三阶段流程**：
1. **评分阶段**：为每条消息计算重要性分数
2. **裁剪阶段**：动态规划选择保留/压缩/丢弃
3. **摘要阶段**：对被裁剪的消息生成摘要

**参数来源**：
- 初始保留数 200：从用户历史行为自适应
- 压缩阈值 0.6：LLM 根据上下文窗口动态评估
- 调整间隔 100：从压缩效果反馈自适应

### A-007：验证通过率算法（风险自适应）

**科学依据**：
- 风险自适应测试（Risk-Based Testing, Amland, 2002）
- 统计学假设检验

**参数来源**：
- 风险等级阈值：由 LLM 根据任务描述动态评估
- 通过率阈值：由风险等级动态确定

### A-008：参数自适应规则
- 所有算法参数初始值必须有科学依据引用
- 运行后从该用户历史数据自适应调整
- 调整幅度有上限（防止剧烈变化）
- 参数变更记录到审计日志
